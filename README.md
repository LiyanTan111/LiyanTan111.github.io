# liyantan111.github.io

Personal academic homepage of [Liyan Tan](https://liyantan111.github.io), built with
[AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) (Jekyll, MIT).

## Editing

- `_pages/about.md` — homepage content
- `_pages/papers/` — per-paper project pages
- `_config.yml` — name, avatar, links
- `assets/css/main.scss` — styling

## Local preview

```bash
bundle install
./run_server.sh   # http://127.0.0.1:4000
```

## Deploy

Push to `main`; GitHub Pages builds it automatically.
