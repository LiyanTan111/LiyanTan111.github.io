Overview

One generalist on the phone, a specialist for every task.

A phone can only hold an LLM of a few billion parameters, well below frontier models. But the tasks people actually run on their phone are narrow and personal. MobileSpec keeps one shared INT4 model on the device, the generalist, and trains a lightweight specialist for each task the user repeats, on the phone, while it is idle.

Backpropagation does not fit in a phone app's memory, and users rarely label data. So MobileSpec trains with forward passes alone, learning from outcomes the device can check automatically or from the user's own records. Each specialist is a 1–5 MB file applied on top of the untouched INT4 weights.

TL;DR

Specialists of 1–5 MB lift a phone-use agent from 6–23% to 89–100% success on three of five tasks, and MobileSpec trains a personalized 8B model on an iPhone 16 Pro overnight, peaking at 3.5 GB of memory.

Method

FuRA-S: search only the block-spectral coordinates.

Forward-only training builds every update from random perturbations, so it learns quickly only when those perturbations look like the weight changes the task needs. FuRA-S picks a search space that is tiny enough to store per task and shaped like the changes RLVR makes.

1

Block-spectral coordinates

Split each weight matrix into column blocks and factor every block by an untruncated SVD, \(W_k = L_k\,\mathrm{diag}(s_k)\,R_k^\top\). Only the block singular values \(s_k\) are trained, about 0.03% of the parameters.

2

Forward-only ES

Score antithetic pairs \(\theta \pm Dz_j\), with each singular value perturbed in proportion to its own size, standardize their fitness, and move toward the better members. Directions are regenerated from seeds and never stored.

3

Runs on INT4 as is

Because nothing is truncated, the update is exactly a transformation of the layer input. The released INT4 weights and kernels stay untouched, and a specialist stores only its vector \(\delta\).

$$W' = W\,(I + E), \qquad E = R\,\mathrm{diag}(\delta)\,R^\top, \qquad y = \underbrace{W_q}_{\text{INT4, frozen}}\bigl(x + R\,\mathrm{diag}(\delta)\,R^\top x\bigr)$$

With \(s'_k = s_k \odot (1+\delta_k)\) and \(R = \mathrm{blockdiag}_k(R_k)\). The frozen \(R\) is stored in 4 bits and shared by all specialists; \(\delta = 0\) recovers the quantized model exactly.

Why rescaling blocks turns the whole matrix Animated

The ellipse is where a toy weight matrix sends the unit sphere: its axes are the output frame, their lengths the singular values. On the right the matrix has two column blocks. Each block keeps its own axes (orange, green) and only stretches, but the two stretch by different amounts, so the axes of the whole matrix, set by \(WW^\top=\sum_k L_k\,\mathrm{diag}(s_k)^2 L_k^\top\), turn. Rescaling the global singular values (left) stretches the axes in place.

Rescaling every block by the same factor rescales the whole matrix and turns nothing. The turn comes from rescaling the blocks independently, which is exactly what ES perturbations do.

Rotation is the largest principal angle between the leading 3-dimensional singular subspaces before and after the update; spectrum change is the relative change of the singular values. Every update is scaled to the same ‖ΔW‖. Toy numbers; on Qwen2.5-1.5B matrices the paper measures about 9° of rotation, four times that of a dense update.

Why it works

The directions of a search space matter more than its size.

ES learns only while some perturbations still beat the current model. In LoRA and full-parameter search spaces that fraction drops to zero within 50 iterations. FuRA-S keeps finding improving perturbations through iteration 125 and reaches the highest accuracy, with as few values as the smaller Uni-LoRA, which drifts furthest from the base model.

Spectral inheritance. Perturbing only the block singular values preserves the spectrum of each weight matrix but rotates both of its frames, and the trained weights inherit the same structure: the rotated frames alone retain over 95% of the accuracy gain on MATH and on Countdown.

Phone agents

From rarely to reliably.

MAI-UI-2B operates real Android apps from screenshots in MobileWorld. On five tasks where it succeeds less than a quarter of the time, a specialist that changes only 516,096 block singular values (0.024% of the model) trains for 15 iterations, 960 episodes. A step-wise fitness credits each action against what the other members did on the same screen, so a good action is rewarded even when the member's own episode fails for other reasons.

RLVR

Full-parameter ES accuracy from 0.05% of the parameters.

On Countdown and MATH, FuRA-S is on par with full-parameter ES while training at most 0.05% of the parameters it perturbs. It outperforms ES over LoRA and VeRA adapters on every model, and without computing a single gradient it surpasses PPO, GRPO and Dr. GRPO on four of five models.

On device

An 8B specialist, trained on an iPhone overnight.

On an iPhone 16 Pro, MobileSpec trains a specialist for one LaMP movie-tagging user on top of the released INT4 Llama-3.1-8B-Instruct, using the likelihood of the user's own records as fitness. The 5.5 GB model is larger than the 5.3 GB an app may use, so MobileSpec streams the decoder layers from flash.
